# GenAI 101 – FAQs & Ethical Use Website 

## Project Overview

This project is a simple, static website that introduces **Generative AI (GenAI)** to beginners.  
It covers:

- Frequently Asked Questions (FAQs) about GenAI
- Ethical use of AI in academe, research, and daily life
- An analogy on the use of AI in development work (the wedding documentation scenario)

The site is designed for students in **CSDC100** and related courses who are new to GenAI.

## Pages

- `index.html` – Landing page with overview and quick links
- `faq.html` – FAQ section about GenAI (definition, how it works, strengths, limitations, etc.)
- `ethics.html` – Ethical use of AI (plagiarism, bias, accuracy, guidelines)
- `article.html` – Analogy: wedding documentation, integrity, and “vibe” coders in dev work
